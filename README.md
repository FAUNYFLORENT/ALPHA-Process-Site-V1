# ALPHA Process — Site V2

Prototype vitrine multi-vues en français.

## Pages
- Accueil
- Process & P&ID interactif
- Parc machine & implantation
- Intelligence IA & chatbot alimentable
- ALPHA Pilot
- Étude projet & configurateur

## Confidentialité
Le site est volontairement `noindex`. Les valeurs, séquences, seuils, programmes, dimensions d’exécution et logiques propriétaires ne sont pas publiés. Le P&ID est une représentation fonctionnelle non exécutable.

## Connecteurs
Les endpoints sont centralisés dans `app.js`, objet `alphaConfig` : `chatbotEndpoint`, `crmEndpoint`, `knowledgeBaseLabel`.
